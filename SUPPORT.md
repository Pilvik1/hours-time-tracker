# Support

Hours Time Tracker is maintained as a pre-release open-source project.

## Questions and bugs

Before opening an issue:

1. Check the current [README](README.md), [roadmap](ROADMAP.md), and existing issues.
2. Confirm the problem occurs on the newest published beta.
3. Remove real work records, passwords, tokens, database files, and personal information from screenshots or logs.

Use the bug-report template for reproducible defects. Include the application version, Windows version, expected behavior, actual behavior, and minimal reproduction steps.

## Security

Do not report suspected vulnerabilities in a public issue. Follow the private process in [SECURITY.md](SECURITY.md).

## Scope

Support is best-effort. The project does not currently provide service-level guarantees, paid support, cloud recovery, or compatibility guarantees for modified binaries.
