# Roadmap

Hours Time Tracker is beta software. This roadmap communicates direction rather than a promise of dates or features.

## Current release line

- Reliable local SQLite persistence and automatic migrations
- One-click calendar entry creation, drag, resize, and overlap layout
- Projects, clients, tags, reports, and XLSX export
- Windows installer and portable builds
- Checksums, SBOM, dependency audits, and frozen-backend runtime gates

## Before a stable 1.0

- Complete a real-device Windows install, upgrade, uninstall, and recovery matrix
- Add a documented backup and restore workflow
- Improve onboarding and first-run guidance
- Establish a code-signing process for Windows releases
- Resolve final public product naming and brand clearance
- Expand accessibility and keyboard-navigation testing

## Later candidates

- Optional CSV import and export
- User-controlled local backup reminders
- Additional desktop platforms when packaging and support can be proven

## Deliberate non-goals

- Mandatory accounts or subscriptions
- Advertising, telemetry, or behavior analytics
- Hosted storage or cloud sync maintained by this project
- Silent collection of work records

Feature proposals should begin with an issue that describes the user problem, privacy impact, maintenance cost, and acceptance criteria.
