# Branding and project name

## Independent project

Hours Time Tracker is an independent open-source project. It is not affiliated with, endorsed by, sponsored by, or connected to Hours, LLC, hourstimetracking.com, or any other similarly named product or company.

The repository name is descriptive working identification for a time-tracking application. No claim of exclusive trademark rights in the word “Hours” is made by this repository.
